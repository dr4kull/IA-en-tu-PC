Requisitos del equipo

Las aplicaciones se ejecutan en Windows y descargan sus motores de IA durante la instalación. Estas son las configuraciones previstas y sus limitaciones.

ComponenteVoice Studio 2.0 RC2MuseTalk Studio 1.6.14
Windows64 bits10/11 de 64 bits
GráficaNVIDIA compatible con CUDA requerida por esta edición; probada con RTX 3080.NVIDIA compatible con CUDA, necesaria para la configuración probada.
ConexiónInternet para la instalación automática de Git, Python, PyTorch y descarga previa de los modelos de voz es-ES.Internet para descargar Python, PyTorch, MuseTalk, FFmpeg y los modelos durante la instalación.
AlmacenamientoVarios gigabytes libres para PyTorch, modelos y resultados. El espacio real depende del entorno y la caché.Varios gigabytes libres para librerías, modelos y resultados. El motor se guarda en %LOCALAPPDATA%\IA_PC_MT; la ruta corta evita el fallo de instalación de MMPose.
PythonEl instalador automático prepara Python 3.11, Git portátil y un entorno virtual independiente.El instalador prepara Python 3.10 privado y el motor en una ruta corta del perfil: %LOCALAPPDATA%\IA_PC_MT.
FormatosEntrada: texto y audio de referencia autorizado. Salida: WAV original y, opcionalmente, WAV con eco reducido.Entrada: imagen/vídeo y WAV. Salida: MP4.
PruebasRC2 probada por el creador con NVIDIA; no se garantiza compatibilidad con todos los ordenadores.Generación real comprobada en un segundo PC con RTX 3080, incluida la corrección de audio.

Instalación recomendada en estas versiones BETA: extrae el ZIP, clic derecho sobre 1_INSTALAR.cmd (Voice Studio) o 1_INSTALAR_TODO.cmd (MuseTalk) → Ejecutar como administrador. Solo desde el repositorio oficial. Esta opción no desactiva SmartScreen ni Smart App Control.
