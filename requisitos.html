Requisitos del equipo

Las aplicaciones se ejecutan en Windows y descargan sus motores de IA durante la instalación. Estas son las configuraciones previstas y sus limitaciones.

ComponenteVoice Studio 1.6.8MuseTalk Studio 1.6.14
Windows64 bits10/11 de 64 bits
GráficaNVIDIA con CUDA recomendada. Otras configuraciones no validadas.NVIDIA compatible con CUDA, necesaria para la configuración probada.
ConexiónInternet para instalar y descargar modelos; la primera transcripción puede necesitar descargas.Internet para instalar PyTorch, MuseTalk y los modelos.
Almacenamiento12 GB libres recomendados como mínimo para empezar; puede requerir más según los modelos.Varios gigabytes libres para librerías, modelos y resultados; recomendamos disponer de margen adicional.
PythonEl instalador prepara Python 3.11 / un entorno independiente.El instalador prepara Python 3.10 privado / un entorno independiente.
FormatosEntrada: texto y referencia de voz propia. Salida: WAV.Entrada: imagen/vídeo y WAV. Salida: MP4.
PruebasBETA probada en Windows, no validada en todas las configuraciones.Generación real comprobada en un segundo PC con RTX 3080, incluida la corrección de audio.
