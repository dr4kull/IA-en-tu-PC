Descarga las aplicaciones

ZIPs gratuitos de nuestras aplicaciones Windows en fase BETA. Los instaladores preparan automáticamente sus dependencias y modelos. Voice Studio incluye Python y Git; MuseTalk utiliza una ruta corta para evitar fallos de MMPose en Windows.

🎙️RC2 · Auto

Voice Studio

Genera voz en español de España con Chatterbox, usando una referencia autorizada. Admite textos largos, reduce el eco de forma opcional y exporta WAV.

Descargar Voice Studio automáticoCómo instalar

Instalación: extrae el ZIP, haz clic derecho sobre 1_INSTALAR.cmd y elige Ejecutar como administrador. Descarga automática de Git, Python 3.11, PyTorch y modelos. Este paso no evita SmartScreen.

Windows 64 bits · NVIDIA CUDA · Chatterbox es-ES
🎬BETA · Ruta corta

MuseTalk Studio

Sincroniza los movimientos de los labios de una persona en vídeo con un archivo de audio WAV mediante MuseTalk 1.5.

Descargar MuseTalk corregidoCómo instalar

Instalación: extrae el ZIP, haz clic derecho en 1_INSTALAR_TODO.cmd y selecciona Ejecutar como administrador. Instala el motor en %LOCALAPPDATA%\IA_PC_MT para evitar errores de rutas largas de mmpose.

Windows 10/11 64 bits · GPU NVIDIA · MP4 + WAV
¿Qué archivo debo descargar? El ZIP completo y corregido de cada aplicación. Extrae todos los archivos antes de empezar y ejecuta el instalador indicado. Las correcciones nuevas requieren descargar su propio ZIP, no instalar la versión antigua.

Antes de instalar

Windows

Windows de 64 bits. Para MuseTalk se requiere gráfica NVIDIA; nuestras pruebas se han realizado con RTX 3080.

Conexión y espacio

Se necesitan Internet y espacio libre para PyTorch, los modelos de IA y otros componentes. Los ZIP no incluyen esos gigabytes.

Licencias
